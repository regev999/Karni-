# קרני תכלת — דף נחיתה למכירת חיסול מתצוגה

דף נחיתה בעברית (RTL) שנבנה פיקסל‑אחר‑פיקסל מקובץ העיצוב `Web 1920 – 13.pdf` (Adobe XD, 1440×13827),
יחד עם אזור ניהול להעלאת תמונות מוצרים וקובץ אקסל. הפנייה נעשית בוואטסאפ — אין טופס
ואין לידים שנשמרים באתר.

PHP 8.1+ בלבד — **בלי Composer, בלי בסיס נתונים, בלי Node בשרת**. מעלים את התיקייה ומסיימים.

---

## התקנה בשרת

1. העלו את כל התיקייה לתיקיית האתר (`public_html` / `httpdocs` / שורש האתר בפאנל).
2. ודאו ש‑PHP 8.1 ומעלה (נבדק על 8.4). בפאנל פרוגינטר: *אתרים → PHP → גרסה*.
3. תנו הרשאת כתיבה לשתי תיקיות בלבד:
   ```bash
   chmod -R 775 data uploads
   ```
4. היכנסו ל‑`https://הדומיין/admin/` — במסך הראשון תגדירו סיסמת ניהול. הסיסמה נשמרת מוצפנת
   (`password_hash`), לא בקוד.
5. ב־*הגדרות* הזינו את **מספר הוואטסאפ של העסק** — לשם מובילים כל הכפתורים בדף —
   ומייל לשחזור סיסמה. עד שיוגדר מספר, הכפתורים מחייגים לטלפון שבפוטר.

### להעלאת אצוות גדולות של תמונות
ברירת המחדל של PHP מגבילה ל‑20 קבצים בבקשה. בפאנל (*אתרים → PHP → הגדרות*) העלו:

| הגדרה | מומלץ |
|---|---|
| `max_file_uploads` | `200` |
| `upload_max_filesize` | `20M` |
| `post_max_size` | `256M` |
| `max_execution_time` | `120` |

אפשר גם להעלות במנות של 20–50 תמונות בכל פעם — התוצאה זהה.

### אבטחה
* **כל קובץ נתונים הוא `.php` שפותח ב‑`<?php http_response_code(404); exit; ?>`** —
  `settings.php` (גיבוב הסיסמה), `views.php` (מונה הצפיות), `logins.php` (מונה
  הניסיונות) ו‑`products.php` (הקטלוג), וגם `products.seed.php` שמגיע עם הקוד.
  זו ההגנה היחידה
  שלא תלויה בהגדרת שרת: היא עובדת גם ב‑nginx בלי `.htaccess` וגם ב‑`php -S`.
* `data/` ו‑`inc/` חסומים גם ב‑`.htaccess`, לשרתי Apache.
* `uploads/` חוסם הרצת סקריפטים.
* אם השרת הוא nginx (בלי `.htaccess`), הוסיפו:
  ```nginx
  location ~ ^/(data|inc|tools)/ { deny all; }
  location ~ ^/uploads/.*\.(php|phtml|cgi|pl|py|sh|html?)$ { deny all; }
  ```
  בפאנל פרוגינטר אין `.htaccess` כברירת מחדל, ואת אותו הדבר עושים ב‑*אתרים →
  הגדרות → ניתובים*: `^/(inc|data|tools)/` → `/blocked-by-rule`, דגל `last`.
  זה מסתיר את קבצי הקוד והכלים; הנתונים עצמם מוגנים גם בלי זה, בזכות שורת ה‑404.
* לחלופין אפשר להוציא את `data/` מחוץ לשורש האתר: צרו `inc/config.local.php` עם
  ```php
  <?php define('DATA_DIR', '/home/USER/private/karni-data');
  ```

## אזור הניהול — `/admin/`

### מוצרים
* **תמונות מוצרים** — גרירה או בחירת קבצים. **שם הקובץ הוא שם המוצר**:
  `KELVIN.jpg` → מוצר בשם `KELVIN`. קו תחתון הופך לרווח. העלאה חוזרת של אותו שם
  מחליפה את התמונה הקיימת ולא יוצרת כפילות. פורמטים: jpg, png, webp, gif, avif.
* **קובץ אקסל** — `xlsx` או `CSV` (כולל CSV שנשמר בקידוד Windows‑1255). העמודות:

  | שם מוצר | מק״ט | מחיר לפני הנחה | מחיר אחרי הנחה | תיאור |
  |---|---|---|---|---|
  | KELVIN | FLS3198 | 2968 | 1240 | מנורת רצפה… |

  עמודת **תיאור** אופציונלית (עד 600 תווים) והיא היחידה שנותנת לעמוד של כל מוצר
  תוכן משלו בגוגל. אפשר גם למלא אותה ישירות בטבלת העריכה. קובץ בלי העמודה הזו
  לא מוחק תיאורים שכבר נכתבו.

  הכותרות מזוהות אוטומטית לפי שם (גם באנגלית); אם אין כותרות — לפי סדר העמודות.
  סימני מטבע ופסיקים במחיר מנוקים לבד. **סדר השורות בקובץ קובע את סדר המוצרים בדף**,
  והמוצרים זורמים ברצף — ארבעה בשורה, בלי חורים. (בקובץ העיצוב יש 34 שורות ובהן
  משבצות ריקות שהמעצב השאיר; באתר חי עם קטלוג אמיתי הן נראות כמו תקלה, אז הגריד
  נסגר ל‑31 שורות מלאות — ומכאן שהדף בנוי נמוך ב‑909 פיקסלים מהקובץ.)
* **עריכת הקטלוג** — טבלה לעריכה ידנית, סינון ומחיקה.
* **מסגור התמונה** — התמונה ממורכזת בחלק העליון של הכרטיס ולא נמתחת על כולו
  (`object-fit: contain` בתיבה של 284×168), כך שהשם והמחירים יושבים תמיד על
  רקע לבן נקי. אין צורך לסמן דבר לכל מוצר — זה עובד לכל תמונה שתעלו, בכל יחס.

### רקע התמונות
**תמונות נכנסות כמו שהן.** חלק מתמונות היצרן מצולמות על רקע אפור בהיר ולא על לבן,
וזה נראה כמו קופסה אפורה בתוך הכרטיס — אם תרצו להלבין את הרקע הזה יש
`php tools/flatten.php` שרץ על תיקייה ומזהה רקע אחיד לבד (המוצר עוצר את המילוי,
והצל שלו נשאר). זה **לא** רץ בהעלאה, בכוונה: תמונה שצולמה מול קיר מואר ולא מול
רקע אחיד עלולה לצאת מכורסמת, ותמונה פגומה גרועה מרקע אפור.

### צפיות במוצרים
עמודת **צפיות** בטבלת הקטלוג סופרת כמה פעמים נפתח הפופ-אפ של כל מוצר. לחיצה על
כותרת העמודה ממיינת מהנצפה ביותר — המיון הוא תצוגתי בלבד ואינו משנה את סדר הדף.

הספירה נעשית מהדפדפן (`api/view.php`), כך שזחלן שעובר על 121 כתובות המוצרים לא
מנפח אותה, וכל מוצר נספר פעם אחת לכל סשן דפדפן. הנתונים ב-`data/views.php`,
לפי ה-slug של המוצר — שינוי שם או מק״ט מתחיל ספירה חדשה.

### וואטסאפ
שדה אחד ב־*הגדרות*: מספר הטלפון של העסק. אפשר לכתוב אותו כמו שרושמים בארץ
(`050-1234567`) או בפורמט בינלאומי (`972501234567`) — שניהם מתורגמים לאותו
`wa.me/972…`. שלושת הכפתורים בדף (מעל הפוטר, בחלון המוצר, והבועה הצפה) נבנים
מהמספר הזה, ואם הוא ריק הם מחייגים לטלפון שבפוטר במקום להוביל לשום מקום.

### הגנה על מסך הכניסה
שלושה ניסיונות ראשונים בלי השהיה — אדם שמקליד לא נכון לא מרגיש כלום. מכאן ההמתנה
מוכפלת בכל ניסיון כושל: 2 שניות, 4, 8… עד תקרה של 15 דקות. זה הופך סקריפט שמנחש
מאלפי ניסיונות בשעה לכמה עשרות.

המונה **לפי כתובת IP ולא גלובלי**, בכוונה: מונה גלובלי היה נותן לתוקף אחד לנעול
אותך מחוץ לפאנל שלך. סיסמה נכונה שמגיעה בזמן ההמתנה נדחית *לפני* הבדיקה, כך
שהמתנה לא מאריכה את עצמה. כניסה מוצלחת מאפסת את המונה, וכתובת שהפסיקה לנסות
נשכחת אחרי שעה. הנתונים ב-`data/logins.php`.

### שכחתי סיסמה
בדף הכניסה יש קישור **שכחתי סיסמה**. הוא שולח קישור חד-פעמי לכתובת המייל שהוגדרה
ב־*הגדרות → אבטחה*: תקף לחצי שעה, לשימוש אחד, ובקשה אחת לכל עשר דקות. נשמר רק ה-hash של
האסימון, והוא נמחק ברגע שנבחרה סיסמה חדשה.

אם עדיין לא הוגדרה כתובת מייל — אין לאן לשלוח, ואז האיפוס הידני: במנהל הקבצים לפתוח
את `data/settings.php`, לשנות `"admin_hash": "..."` ל-`"admin_hash": ""`, לשמור,
ולהיכנס ל-`/admin/` — יופיע מסך ההגדרה הראשונית. **בין השמירה לבחירת הסיסמה כל מי
שייכנס יכול לתפוס אותה**, אז לעשות את זה ברצף.

### הגדרות
מספר הוואטסאפ, כותרת ותיאור לדף, טלפון וכתובת בפוטר, מייל לשחזור סיסמה, ושינוי סיסמה.
בנוסף **חסימת אינדוקס** — מתג אחד שמכבה את האתר למנועי חיפוש ול-AI (`noindex, nofollow`
בדף ו-`Disallow: /` ב-robots.txt). נועד לכתובת זמנית, כדי שהיא לא תתחרה בדומיין הסופי.
אזור הניהול זוכר על איזו כתובת הופעלה החסימה, וברגע שהאתר עונה על כתובת אחרת הוא מציג
תזכורת בולטת לכבות אותה.

## חלון המוצר (פופ-אפ)

לחיצה על מוצר פותחת חלון עם התמונה, השם, המק״ט, המחיר לפני ואחרי, ותג חיסכון מחושב —
ובתוכו כפתור וואטסאפ. **אין רכישה באתר ואין חיוב**; החלון רק פותח שיחה.

* **המק״ט, שם המוצר והמחיר כבר כתובים בהודעה** שנפתחת, כך שהלקוח לא מעתיק כלום
  ואתם יודעים מיד על מה מדובר.
* נבנה על `<dialog>` — סגירה ב‑X, בלחיצה על הרקע או ב‑Esc, מלכודת פוקוס ונעילת גלילה
  מגיעות מהדפדפן. בדפדפן ישן ללא תמיכה, לחיצה על מוצר פותחת את כתובת המוצר עצמה,
  שמוגשת מהשרת עם אותם פרטים ואותו כפתור.
* במובייל החלון עולה מלמטה כגיליון, עם כפתור הוואטסאפ וכפתור חיוג מתחתיו.
* על מסכי מגע רצועת ״לפרטים ויצירת קשר״ מוצגת תמיד בכרטיס; בעכבר היא עולה במעבר.

## איך פונים אליכם

אין טופס ואין שרת שמחזיק פרטי לקוחות — בדף יש שלושה כפתורי וואטסאפ, וכולם
`https://wa.me/<מספר>?text=<הודעה>`:

| איפה | מה כתוב בהודעה |
|---|---|
| מעל הפוטר | פנייה כללית על המכירה מתצוגה |
| בחלון המוצר, ובכרטיס עצמו | שם המוצר, המק״ט והמחיר הנוכחי |
| הבועה הצפה | פנייה כללית, מכל מקום בדף |

הלקוח לוחץ, וואטסאפ נפתח עם ההודעה כתובה, והוא רק שולח. כל מה שנשמר אצלנו הוא
מונה הצפיות — בלי שם, בלי טלפון ובלי מייל.

## SEO

* **כתובת לכל מוצר.** כל כרטיס הוא קישור אמיתי ל‑`?p=<slug>`, וה‑slug נגזר מהשם
  ומהמק״ט ולא ממיקום המוצר בקטלוג — כך שהכתובת לא זזה כשמוסיפים או מוחקים שורה.
  הכתובת הזו מוגשת מהשרת עם הכותרת, התיאור, ה‑canonical והסכמה של אותו מוצר,
  ופרטי המוצר מודפסים לתוך הפופ‑אפ ב‑HTML — לא רק על ידי הסקריפט. הגלישה עצמה
  לא משתנה: לחיצה פותחת פופ‑אפ ומעדכנת את הכתובת, וכפתור "אחורה" סוגר אותו.
* **סכמה** (`application/ld+json`): `WebSite`, `HomeGoodsStore` עם טלפון וכתובת,
  `CollectionPage` + `ItemList` של כל המוצרים בדף הראשי, ובעמוד מוצר גם
  `Product` + `Offer` (מחיר בשקלים, מלאי, מוכר) ו‑`BreadcrumbList`.
* **`robots.txt` ו‑`sitemap.xml`** נכתבים על ידי האתר עצמו מהדומיין הנוכחי
  ומהקטלוג הנוכחי, ומתרעננים כשהקטלוג משתנה. אין צורך לערוך אותם ואין צורך
  בכלל rewrite — לכן הם גם לא ב‑git.
* **תצוגה מקדימה בשיתוף** (וואטסאפ, פייסבוק): `assets/img/og.jpg` בגודל
  1200×630. נבנה מחדש עם `node tools/og.mjs`.
* **מבנה כותרות**: `h1` אחד בהירו, `h2` לשלבים ולפנייה, `h2.sr-only` לגלריה,
  ו‑`h3` לשם כל מוצר.

## מבנה הפרויקט

```
index.php              דף הנחיתה
api/view.php           ספירת פתיחות פופ-אפ
admin/                 אזור הניהול
inc/                   bootstrap, אחסון, הרשאות, קורא אקסל, מייל איפוס, SEO, עיבוד תמונה
assets/css|js|fonts    עיצוב, סקריפט, ופונטים מקומיים (Alef + Montserrat)
assets/img             hero, לוגו, 70%, ספרות השלבים, עגלה — חולצו מה‑PDF
uploads/products       תמונות המוצרים
data/                  products.php (הקטלוג החי), products.seed.php (הקטלוג שמגיע עם הקוד),
                       settings.php, views.php, logins.php — כולם מאחורי שורת 404
tools/                 כלי פיתוח בלבד — לא נדרשים בשרת
```

### דיוק מול העיצוב

כל מידה ב‑`assets/css/site.css` כתובה כ‑`calc(<פיקסל בעיצוב> * var(--u))`, כאשר
`--u` שווה בדיוק לפיקסל אחד ברוחב 1440 ומתכווץ יחסית מתחת לזה — כך שהמספרים בקוד
הם המספרים בקובץ העיצוב. מתחת ל‑900px נכנס פריסת מובייל ייעודית.

הפונטים אומתו מול מדידות רוחב מדויקות מתוך ה‑PDF: **Alef** לעברית, **Montserrat** ללטינית ולמספרים.

### כלי פיתוח (`tools/`)

```bash
python3 tools/extract_catalog.py design.pdf   # מחלץ 121 מוצרים + תמונות מה-PDF
python3 tools/extract_assets.py  design.pdf   # מחלץ לוגו, 70%, ספרות, hero, עגלה
python3 tools/reference.py       design.pdf   # מרנדר את העיצוב ל-PNG להשוואה
node tools/shoot.mjs                          # צילום מסך + השוואת פיקסלים לעיצוב
node tools/mobile.mjs                         # צילומי מובייל/טאבלט + בדיקת גלישה אופקית
node tools/modal-shots.mjs                    # צילומי חלון המוצר
node tools/e2e.mjs                            # בדיקת קצה-לקצה: ניהול, וואטסאפ וחלון המוצר
node tools/seo.mjs                            # בדיקת SEO: מטא, סכמה, sitemap, robots, כתובות מוצר, מונה צפיות
node tools/og.mjs                             # בונה מחדש את תמונת השיתוף 1200x630
php  tools/flatten.php                        # מלבין רקע אפור בתמונות מוצר
node tools/mockup/render.mjs && python3 tools/mockup/topdf.py   # מוקאפ החלון ל-PDF
```

הרצה מקומית: `php -S 127.0.0.1:8088 -t .`

> `tools/` מוגן ב‑`.htaccess` וניתן פשוט למחוק אותו מהשרת.
