# קרני תכלת — דף נחיתה למכירת חיסול מתצוגה

דף נחיתה בעברית (RTL) שנבנה פיקסל‑אחר‑פיקסל מקובץ העיצוב `Web 1920 – 13.pdf` (Adobe XD, 1440×13104),
יחד עם אזור ניהול להעלאת תמונות מוצרים וקובץ אקסל, וטופס לידים.

PHP 8.1+ בלבד — **בלי Composer, בלי בסיס נתונים, בלי Node בשרת**. מעלים את התיקייה ומסיימים.

---

## התקנה בשרת

1. העלו את כל התיקייה לתיקיית האתר (`public_html` / `httpdocs` / שורש האתר בפאנל).
2. ודאו ש‑PHP 8.1 ומעלה (נבדק על 8.4). בפאנל פרוגינטר: *אתרים → PHP → גרסה*.
3. תנו הרשאת כתיבה לשתי תיקיות בלבד:
   ```bash
   chmod -R 775 data uploads
   ```
4. היכנסו ל‑`https://הדומיין/admin/` — במסך הראשון תגדירו סיסמת ניהול. הסיסמה נשמרת מוצפנת
   (`password_hash`), לא בקוד.
5. ב־*הגדרות* הזינו כתובות מייל לקבלת לידים, ובמידת הצורך כתובת Webhook.

### להעלאת אצוות גדולות של תמונות
ברירת המחדל של PHP מגבילה ל‑20 קבצים בבקשה. בפאנל (*אתרים → PHP → הגדרות*) העלו:

| הגדרה | מומלץ |
|---|---|
| `max_file_uploads` | `200` |
| `upload_max_filesize` | `20M` |
| `post_max_size` | `256M` |
| `max_execution_time` | `120` |

אפשר גם להעלות במנות של 20–50 תמונות בכל פעם — התוצאה זהה.

### אבטחה
* `data/` ו‑`inc/` חסומים ב‑`.htaccess`; בנוסף `data/settings.php` ו‑`data/leads.php` פותחים
  ב‑`<?php ... exit;` כך שגם שרת שמתעלם מ‑`.htaccess` לא ידלוף.
* `uploads/` חוסם הרצת סקריפטים.
* אם השרת הוא nginx (בלי `.htaccess`), הוסיפו:
  ```nginx
  location ~ ^/(data|inc|tools)/ { deny all; }
  location ~ ^/uploads/.*\.(php|phtml|cgi|pl|py|sh|html?)$ { deny all; }
  ```
* לחלופין אפשר להוציא את `data/` מחוץ לשורש האתר: צרו `inc/config.local.php` עם
  ```php
  <?php define('DATA_DIR', '/home/USER/private/karni-data');
  ```

## אזור הניהול — `/admin/`

### מוצרים
* **תמונות מוצרים** — גרירה או בחירת קבצים. **שם הקובץ הוא שם המוצר**:
  `KELVIN.jpg` → מוצר בשם `KELVIN`. קו תחתון הופך לרווח. העלאה חוזרת של אותו שם
  מחליפה את התמונה הקיימת ולא יוצרת כפילות. פורמטים: jpg, png, webp, gif, avif.
* **קובץ אקסל** — `xlsx` או `CSV` (כולל CSV שנשמר בקידוד Windows‑1255). העמודות:

  | שם מוצר | מק״ט | מחיר לפני הנחה | מחיר אחרי הנחה |
  |---|---|---|---|
  | KELVIN | FLS3198 | 2968 | 1240 |

  הכותרות מזוהות אוטומטית לפי שם (גם באנגלית); אם אין כותרות — לפי סדר העמודות.
  סימני מטבע ופסיקים במחיר מנוקים לבד. **סדר השורות בקובץ קובע את סדר המוצרים בדף.**
* **עריכת הקטלוג** — טבלה לעריכה ידנית, סינון ומחיקה.
* **מסגור התמונה** — התמונה ממורכזת בחלק העליון של הכרטיס ולא נמתחת על כולו
  (`object-fit: contain` בתיבה של 284×168), כך שהשם והמחירים יושבים תמיד על
  רקע לבן נקי. אין צורך לסמן דבר לכל מוצר — זה עובד לכל תמונה שתעלו, בכל יחס.

### לידים
טבלה של כל הפניות עם שם המוצר, המק״ט והמקור, קישורי חיוג ווואטסאפ,
וייצוא ל‑CSV עם BOM (נפתח נכון באקסל בעברית).

### הגדרות
כתובות מייל, Webhook, כותרת ותיאור לדף, טלפון וכתובת בפוטר, ושינוי סיסמה.
כפתור **שליחת ליד בדיקה** מוודא שהדואר והוובהוק עובדים.

## חלון המוצר (פופ-אפ)

לחיצה על מוצר פותחת חלון עם התמונה, השם, המק״ט, המחיר לפני ואחרי, ותג חיסכון מחושב —
ובתוכו טופס יצירת קשר. **אין רכישה באתר**; החלון רק לוכד ליד.

* **המק״ט ושם המוצר מוטבעים אוטומטית** בפנייה, כך שהלקוח לא מעתיק כלום.
* נבנה על `<dialog>` — סגירה ב‑X, בלחיצה על הרקע או ב‑Esc, מלכודת פוקוס ונעילת גלילה
  מגיעות מהדפדפן. בדפדפן ישן ללא תמיכה, לחיצה על מוצר מעבירה את המק״ט לטופס שבפוטר.
* במובייל החלון עולה מלמטה כגיליון, עם כפתור שליחה נעוץ לתחתית וכפתור חיוג לצידו.
* על מסכי מגע רצועת ״לפרטים ויצירת קשר״ מוצגת תמיד בכרטיס; בעכבר היא עולה במעבר.

## איך הלידים מגיעים

טופס (בפוטר או בחלון המוצר) → `api/lead.php` → שלושה יעדים במקביל:

1. **שמירה** ל‑`data/leads.php` (עם נעילת קובץ, בטוח לשליחות במקביל), כולל שם המוצר,
   המק״ט והמקור (חלון מוצר / טופס).
2. **מייל** לכל הכתובות שהוגדרו, HTML בעברית, עם `Reply-To` של הפונה.
3. **Webhook** — POST עם JSON. לחיבור לוואטסאפ: צרו תרחיש ב‑Make/Zapier עם טריגר
   *Custom Webhook*, הדביקו את הכתובת בהגדרות, וחברו לשלב *WhatsApp Business*.

הגנות: שדה מלכודת לבוטים, ולידציה בצד שרת, והגבלה של שליחה אחת לדקה לכל כתובת IP.

## מבנה הפרויקט

```
index.php              דף הנחיתה
api/lead.php           קליטת לידים
admin/                 אזור הניהול
inc/                   bootstrap, אחסון, הרשאות, קורא אקסל, שליחת התראות
assets/css|js|fonts    עיצוב, סקריפט, ופונטים מקומיים (Alef + Montserrat)
assets/img             hero, לוגו, 70%, ספרות השלבים, עגלה — חולצו מה‑PDF
uploads/products       תמונות המוצרים
data/                  products.json, settings.php, leads.php
tools/                 כלי פיתוח בלבד — לא נדרשים בשרת
```

### דיוק מול העיצוב

כל מידה ב‑`assets/css/site.css` כתובה כ‑`calc(<פיקסל בעיצוב> * var(--u))`, כאשר
`--u` שווה בדיוק לפיקסל אחד ברוחב 1440 ומתכווץ יחסית מתחת לזה — כך שהמספרים בקוד
הם המספרים בקובץ העיצוב. מתחת ל‑900px נכנס פריסת מובייל ייעודית.

הפונטים אומתו מול מדידות רוחב מדויקות מתוך ה‑PDF: **Alef** לעברית, **Montserrat** ללטינית ולמספרים.

### כלי פיתוח (`tools/`)

```bash
python3 tools/extract_catalog.py design.pdf   # מחלץ 117 מוצרים + תמונות מה-PDF
python3 tools/extract_assets.py  design.pdf   # מחלץ לוגו, 70%, ספרות, hero, עגלה
python3 tools/reference.py       design.pdf   # מרנדר את העיצוב ל-PNG להשוואה
node tools/shoot.mjs                          # צילום מסך + השוואת פיקסלים לעיצוב
node tools/mobile.mjs                         # צילומי מובייל/טאבלט + בדיקת גלישה אופקית
node tools/modal-shots.mjs                    # צילומי חלון המוצר
node tools/e2e.mjs                            # בדיקת קצה-לקצה: ניהול, טופס וחלון המוצר
node tools/mockup/render.mjs && python3 tools/mockup/topdf.py   # מוקאפ החלון ל-PDF
```

הרצה מקומית: `php -S 127.0.0.1:8088 -t .`

> `tools/` מוגן ב‑`.htaccess` וניתן פשוט למחוק אותו מהשרת.
